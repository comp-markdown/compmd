# CompMD Guides

Two books about [CompMD](https://compmd.hakanserce.com/), one for writing documents and one for building with the packages. The [spec](../compmd-spec-v1.md) says what CompMD is; the guides teach it.

- **[CompMD Author's Guide](authors/README.md)**: for people who write documents in CompMD, and components in CompMD itself: the syntax, data, inputs, layout, definitions, and the packs a document uses. No code needed.
- **[CompMD Developer's Guide](developers/README.md)**: for developers who put CompMD in an application or write packs: the packages, the sandbox and its trust levels, components in React, Svelte or JavaScript, and publishing.

On the website they are at [compmd.hakanserce.com/guides/](https://compmd.hakanserce.com/guides/). Their examples are tested: each chapter's code and documents are files in its book's `examples/`, which this folder's tests check against the chapters, process, build and run.
