# CompMD Guides

Two books about [CompMD](https://compmd.hakanserce.com/), one for writing documents and one for building with the packages. The [spec](../compmd-spec-v1.md) says what CompMD is; the guides teach it.

- **[CompMD Author's Guide](authors/README.md)**\
  For people who write documents in CompMD, and components in CompMD itself: the syntax, data, inputs, layout, definitions, and the packs a document uses. No code needed.
- **[CompMD Developer's Guide](developers/README.md)**\
  For developers who put CompMD in an application or write packs: the packages, the sandbox and its trust levels, components in React, Svelte or JavaScript, and publishing.
